# Particle Spoilers
Particle Spoilers for Obsidian is a plugin that brings interactive spoiler effects right into your notes. It hides sensitive text using your choice of two styles: a dynamic animation of shimmering particles (a "dust" effect) or a solid color block (similar to Discord or Steam). The plugin is perfect for hiding answers to questions, plot spoilers, or personal data, revealing the text with a simple click.

# Usage

Using the plugin is as simple as applying standard Markdown formatting.

- **Syntax:** To hide text, simply wrap it in double vertical bars `||`. _Example:_ `||This is a secret message||`
     
- **Settings:** Go to the plugin settings to customize it to your liking:

    - Spoiler style: Choose between the classic "Particle" (animated dust) and the new "Block" (solid color rectangle like Discord/Steam).

    - Block spoiler color: If using the Block style, you can choose to use your app's accent color or pick a custom color via a color picker.

    - Particle density and speed: Control the number of particles and their movement speed (Particle style only).

    - Hide on mouse leave: The text will automatically close when you move your mouse away from the spoiler.

    - Disable effect in Edit mode: Choose whether the effect should work in Live Preview or only in Reading mode.

## Install

### Manually

1. Copy `main.js`, `manifest.json`, and `styles.css` into `<your vault>/.obsidian/plugins/particle-spoilers/`.
2. **Settings → Community plugins → Enable Particle Spoilers.**
